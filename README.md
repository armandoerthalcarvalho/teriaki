# 🍣 Teriaki

Gerenciador de vida pessoal completo, gratuito e offline. Organize notas, tarefas, eventos, hábitos e muito mais em um único arquivo HTML.

## Sobre

Teriaki é uma aplicação web single-file que funciona inteiramente no navegador, sem necessidade de servidor, instalação ou conexão com a internet. Todos os dados são armazenados localmente no dispositivo do usuário via `localStorage`.

## Recursos

- 📝 **Notas Ricas** — Editor completo com formatação
- ✅ **Tarefas** — Gestão com prioridades e prazos
- 📅 **Calendário** — Visualização mensal de eventos
- ⏱️ **Pomodoro** — Timer configurável para foco
- 🎯 **Hábitos** — Rastreamento com sequências
- 🦞 **Flashcards** — Sistema completo para revisão
- 🧠 **Quizzes** — Múltipla escolha e discursivo
- 📄 **Editor WEBpro** — Documentos profissionais
- 📊 **SLIDEpro** — Criador de apresentações (12 temas, 26 transições)
- 🤖 **Estudo Profundo** — IA integrada com múltiplos modos (via Groq)
- 📈 **Análises** — Estatísticas e conquistas
- 🎨 **Temas** — Claro, escuro e personalizado
- 🏭 **Enterprise** — Automatize suas tarefas de forma realmente útil com IA

## Como Usar

1. Abra o TeriakiAbout (index.html) 
2. Baixe o arquivo HTML da versão desejada
3. Abra no seu navegador preferido (Chrome, Firefox, Edge, Safari)
4. Pronto — todos os dados são salvos automaticamente no seu dispositivo

Para usar em múltiplos dispositivos, exporte e importe seus dados através das configurações do app.

## Página do Projeto

O arquivo `index.html` é a landing page do Teriaki (TeriakiAbout), com informações sobre o projeto, recursos, downloads e notícias.

## Características Principais

- **100% Offline** — Funciona sem internet
- **100% Privado** — Dados ficam apenas no seu dispositivo
- **Totalmente Gratuito** — Sem limites, sem assinaturas
- **Leve e Rápido** — Um único arquivo HTML, carrega instantaneamente
- **Single-file** — Sem dependências externas para funcionar
